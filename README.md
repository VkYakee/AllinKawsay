## ✨ Sobre el proyecto

**Allin Kawsay** — *Buen vivir* — nace del cariño por nuestras raíces, de la fuerza de los sikuris y del deseo de mantener nuestra cultura presente en cada generación.

Este repositorio contiene el desarrollo de la aplicación móvil del conjunto **Allin Kawsay**, un espacio digital pensado para acercar a sus integrantes, compartir su música y fortalecer los lazos que nos unen.

Más que una aplicación, es una pequeña expresión de identidad, comunidad y orgullo por nuestra tradición andina.

## 🎶 ¿Qué encontrarás?

La aplicación reúne herramientas y espacios digitales relacionados con la vida del conjunto:

- **🎵 Música:** reproducción y contenido musical.
- **📸 Contenido multimedia:** imágenes y videos para compartir momentos y recuerdos.
- **📍 Ubicación y mapas:** recursos de localización vinculados a la comunidad.
- **👥 Comunidad:** funciones conectadas para acompañar la participación de sus integrantes.
- **☁️ Servicios en línea:** integración con Firebase para servicios de la aplicación.

> Las funciones disponibles pueden evolucionar a medida que el proyecto continúa creciendo.

## 📁 Estructura del proyecto

La organización principal del código se encuentra en:

- `lib/` — Código fuente de Flutter.
- `lib/features/` — Funcionalidades de la aplicación.
- `lib/core/` — Componentes y lógica central.
- `lib/data/` — Recursos y manejo de datos.
- `lib/services/` — Servicios e integraciones.
- `assets/` — Recursos visuales y musicales.
- `android_config/` — Configuración relacionada con Android.
- `firebase/` — Recursos de configuración de Firebase.
- `docs/` — Documentación y recursos del proyecto.

## 🚀 Desarrollo

Este proyecto utiliza Flutter. Para preparar un entorno de desarrollo:

1. Instala [Flutter](https://docs.flutter.dev/get-started/install) y configura Android.
2. Clona el repositorio:
   ```bash
   git clone https://github.com/VkYakee/AllinKawsay.git
   cd AllinKawsay
   ```
3. Instala las dependencias:
   ```bash
   flutter pub get
   ```
4. Ejecuta la aplicación en un dispositivo o emulador:
   ```bash
   flutter run
   ```

> Para ejecutar correctamente las funciones conectadas, configura las credenciales y servicios de Firebase que correspondan. No publiques claves privadas ni archivos sensibles.
